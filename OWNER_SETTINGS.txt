AAAM EVENTS — COMPLETE STATIC WEBSITE

QUICK START
Extract the ZIP and open the project using VS Code Live Server or a static web
host. Keep every page on the same domain/origin so browser spin history works
across pages. Direct file:// opening is not reliable for shared browser storage
or saving captured video frames. No backend or build step is required.

ONE OWNER SETTINGS FILE
Edit assets/experience-config.js:
- maxSpins: 2 sets the total spins per browser. Change this number as needed.
- prizes changes wheel labels, result messages, percentage metadata and colours.
- resultSequence sets the exact first, second and subsequent results by prize ID.
  The current demo is first: 40% OFF; second: FREE WELCOME BOARD.
  Every sequence ID must exist in prizes. If you allow more spins than sequence
  entries, the sequence repeats.
- offerValidDays: null keeps offers without expiry; a number sets validity in days.
- campaignId changes reset browser history for a deliberately new campaign.
- greeting / greetingText change the first-visit invitation.
- terms changes the offer terms shown in the wheel and WhatsApp message.
- socials contains dummy Instagram, Facebook and YouTube platform links.
  Replace all three with your real account URLs before launch.
- whatsapp changes the number used for offer claims and the booking enquiry.

HOW IT WORKS
Spin & Win is visible on every page. The greeting is shown once per browser for
this campaign. Its X closes only the greeting. The wheel has its own X and
supports Escape. Closing during a spin does not erase the awarded result or
return the consumed spin. The result is saved before the animation starts.
The first earned offer is selected automatically. Visitors can choose one of
their earned, unexpired offers in the wheel or on Plan Your Event. Offers never
stack. The chosen offer appears in the booking summary and its WhatsApp enquiry.
The existing enquiry form has no priced service total, so a 40% offer is shown
as an offer on the enquiry, not a calculated invoice or checkout discount.
The visitor must press Send inside WhatsApp; the owner gets no automatic message
from merely spinning. Browser history can be cleared or changed; this is a
static demonstration, not a secure per-person reward system.
